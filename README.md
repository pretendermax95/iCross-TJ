# iCross TJ

Адаптивный интернет-магазин кроссовок на Go: каталог, поиск и фильтры, выбор размера, корзина и оформление заказа.

## Запуск

Нужен Go 1.22 или новее. В папке проекта выполните:

```powershell
go run .
```

Откройте [http://localhost:8080](http://localhost:8080). Чтобы изменить адрес сервера, задайте переменную окружения `ADDR`, например `$env:ADDR=":3000"`.

## API

- `GET /api/products` — каталог товаров.
- `POST /api/orders` — проверка и оформление заказа; сервер сам рассчитывает сумму.

Заказы принимаются сервером, но пока хранятся только в памяти процесса. Онлайн-оплата и подключение службы доставки не настроены.
