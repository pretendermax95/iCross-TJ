# iCross TJ

Адаптивный интернет-магазин кроссовок на Go: каталог, поиск и фильтры, выбор размера, корзина и оформление заказа.

## Запуск

Нужен Go 1.22 или новее. В папке проекта выполните:

```powershell
go run .
```

Откройте [http://localhost:8080](http://localhost:8080). Чтобы изменить адрес сервера, задайте переменную окружения `ADDR`, например `$env:ADDR=":3000"`.

## Бесплатное размещение на Render

1. Откройте [страницу развёртывания iCross TJ на Render](https://render.com/deploy?repo=https://github.com/pretendermax95/iCross-TJ).
2. Войдите в Render или создайте аккаунт и подключите GitHub.
3. Подтвердите создание сервиса из Blueprint. Render соберёт приложение и выдаст публичный адрес `*.onrender.com`.

Бесплатный сервис Render может засыпать при простое; первый запрос после паузы может загружаться дольше. Заказы хранятся в памяти процесса и сбрасываются при перезапуске сервиса.

## API

- `GET /api/products` — каталог товаров.
- `POST /api/orders` — проверка и оформление заказа; сервер сам рассчитывает сумму.

Заказы принимаются сервером, но пока хранятся только в памяти процесса. Онлайн-оплата и подключение службы доставки не настроены.
